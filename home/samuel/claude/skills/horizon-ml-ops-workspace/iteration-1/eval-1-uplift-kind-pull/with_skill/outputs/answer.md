## Important: `--kind` is required here

The `uplift-order-predictor` training loop logs one MLflow run **per algorithm** (e.g. `HistGradientBoosting`, `DummyRegressor`), and the logged-model artifact is named after the algorithm — nothing on the run itself distinguishes primary uplift from uplift correction. The skill therefore requires you to pass `--kind uplift_correction` explicitly, which routes the download into the correct `models/uplift_correction/` subfolder of the test repo.

Picking the wrong `--kind` (or omitting it) drops the model into the wrong folder.
